# SaucerPay

Scaffold-HBAR template: invoice in USDC, pay with any Hedera token via SaucerSwap, settle HTS escrow, stamp HCS receipts.

```bash
npm create scaffold-hbar@latest -- --template BikramBiswas786/saucerpay
```
